# Privacy / 隐私说明

First Light Community 1.1.1 — 2026-10-20

本简版不提供账号、支付、云同步、广告或应用内分析服务。收藏、语言偏好和学习进度保存在当前浏览器的本地存储中，不会由本应用上传到服务器。不同设备和浏览器之间不会自动同步。清除浏览器数据会丢失记录，请先在“我的”中导出备份。

设备朗读调用浏览器/操作系统的语音服务；可用音色、语言、自然度和联网要求因设备而异。某些系统声音可能使用供应商的在线服务，不能将“设备朗读”理解为保证完全离线。朗读只在主动点击后开始，切换页面会停止。

页面、经文、字体与图片从部署本网站的主机下载。GitHub Pages 或其他托管商可能按其政策记录网络请求（例如 IP 地址）。打开博物馆或出版社链接时，会访问相应第三方网站。

删除本机记录：进入“我的”，选择清除数据并确认。导出的 JSON 包含个人收藏和进度，请自行妥善保存。请不要将个人备份提交到公开 GitHub 仓库。

This edition has no account, payments, cloud sync, advertising or in-app analytics. Preferences, bookmarks and learning progress are stored in this browser only. They are not uploaded by the application. Clearing browser data removes these records; export a backup first.

Read-aloud uses the browser/operating system speech service. Voices and quality vary by device. Some system voices may use an online provider, so device speech is not a guarantee of fully offline processing. Speech starts only on request and stops when navigating.

The hosting provider serves pages and assets and may keep request logs under its own policy. Following source links takes you to external museum or publisher websites. Exported backups contain your local records; keep them private. Use the confirmed clear-data action in My Library to remove local records.


## Reviews and feedback / 评价与反馈

评价入口会打开 GitHub 的外部表单，需要 GitHub 账号。只有你在 GitHub 确认提交后才会发布；评价、评分、GitHub 用户名和评论将公开显示。维护者会将这些公开反馈和 GitHub 提供的仓库汇总指标纳入自己的每日运营邮件。不会自动上传你的收藏、阅读记录或备份。请勿在反馈中填写私人资料。

Review links open an external GitHub form and require a GitHub account. Nothing is submitted until you confirm on GitHub. Submitted reviews, ratings, GitHub usernames and comments are public. The maintainer summarizes public feedback and aggregate GitHub repository metrics in a private daily operations email. The app does not automatically send your bookmarks, reading history or backups. Keep personal information out of public feedback.
